# SNS Hub

5개 SNS(Facebook · Threads · Instagram · LinkedIn · X)를 **한 앱에서 열어 직접 쓰는** 다크모드 안드로이드 앱.
여기에 **내 콘텐츠(블로그·유튜브) 모아보기 + 캡션 초안 + 공식 공유**를 더한 수동 크로스포스터.

## 무엇인가
- **자동화 도구가 아니다.** 친구 추가·팔로우·연결 신청·좋아요·댓글 등 모든 동작은 열린 화면에서 **사용자가 직접** 누른다.
- **세 가지 핵심 기능**
  1. **콘텐츠 대시보드** — 내 네이버 블로그/유튜브 RSS를 가져와 제목·링크로 **캡션 초안**을 만든다(직접 수정 가능). 복사하거나 "다른 앱으로 공유"(시스템 공유 시트)로 내보낸다.
  2. **인앱 브라우저 / 앱 열기** — 각 SNS를 앱 내 브라우저(WebView, 쿠키·로그인 유지, 파일 업로드 지원)로 열거나, 설치된 네이티브 앱을 띄운다(없으면 Play 스토어).
  3. **이 캡션으로 공유** — 캡션을 **각 플랫폼의 공식 작성 화면**으로 넘긴다. 게시 버튼은 **사람이 직접** 누른다.
     - X: `intent/tweet`, Threads: `intent/post`, Facebook: `sharer`, LinkedIn: `share-offsite` (모두 공식 엔드포인트)
     - Instagram(피드 웹 작성 미제공): 캡션을 클립보드에 복사하고 앱을 연다 → 붙여넣기.
- **SNS별 콘텐츠 언어(한국어/English)** 를 따로 고를 수 있다(웹뷰 진입 시 `Accept-Language`). 카드별 선택은 저장된다.
- 전체 **다크모드**.

## 의도적으로 넣지 않은 것 (설계 원칙)
플랫폼 약관 위반/스팸이 되는 요소는 넣지 않는다.
- 접근성 서비스·JS 주입을 통한 자동 클릭/팔로우/좋아요/댓글
- 동작 큐·자동 반복·딜레이·랜덤 타이밍(밴 회피)
- 친구 후보(낯선 사람) 대량 수집/타겟 리스트
- 정형 댓글 자동 살포, 확인창 자동 통과

즉 이 앱은 "내 콘텐츠를 5개 SNS로 **편하게, 직접** 올리도록 돕는 전용 브라우저/공유 도구"이며, 실제 게시는 사람이 한다.

## 구조
```
android/
  app/src/main/
    java/com/snshubcl/app/
      MainActivity.kt    # 대시보드(콘텐츠 카드 + 5개 SNS 카드, 언어 토글, 열기/공유)
      WebActivity.kt     # 인앱 브라우저(쿠키 유지, 뒤로/새로고침, 파일 업로드) — 자동화 없음
      ContentCrawler.kt  # 내 블로그/유튜브 RSS 파서(백그라운드 스레드)
      Sns.kt             # 플랫폼 정의 + 공식 공유(작성) URL
    res/layout/          # activity_main, item_content_sync, item_sns, activity_web
    res/values(-en)/     # 문자열(한/영), 색상, 다크 테마
```

## 빌드 (CI)
로컬 툴체인 없이 GitHub Actions로 빌드한다.
1. `https://github.com/dicacros-gif/snshubcl` 에 푸시
2. **Actions → Build APK** 자동 실행(`android/**` 변경 시)
3. 결과물: Release `latest` 의 `app-debug.apk`

## 참고
- 로그인된 상태에서는 사이트 표시 언어가 **계정 설정**을 따른다. 한/영 토글은 주로 로그아웃 진입/첫 로드의 언어에 영향을 준다.
- 공식 공유 화면이 캡션을 미리 채워주는 정도는 플랫폼마다 다르다(특히 Facebook/LinkedIn sharer는 링크 기반). 그래서 공유 시 캡션을 **항상 클립보드에도 복사**해 둔다.
- 각 플랫폼의 이용약관과 커뮤니티 정책을 준수해 직접, 상식적인 범위에서 사용할 것.
