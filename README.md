# SNS Hub

5개 SNS(Facebook · Threads · Instagram · LinkedIn · X)를 **한 앱에서 열어 직접 쓰는** 다크모드 안드로이드 앱.

## 무엇인가
- **자동화 도구가 아니다.** 친구 추가·팔로우·연결 신청 등 모든 동작은 열린 화면에서 **사용자가 직접** 누른다.
- 두 가지 열기 방식:
  - **웹뷰로 열기** — 앱 내 브라우저(WebView)로 해당 플랫폼을 연다. 쿠키가 유지되어 로그인 세션이 살아있고, 로그아웃 상태면 첫 화면이 그 플랫폼 로그인 화면이다.
  - **앱으로 열기** — 설치된 네이티브 앱을 띄운다(없으면 Play 스토어).
- **SNS별 콘텐츠 언어(한국어/English)** 를 따로 고를 수 있다(웹뷰 진입 시 `Accept-Language`). 카드별 선택은 저장된다.
- 전체 **다크모드**.

## 의도적으로 넣지 않은 것 (설계 원칙)
플랫폼 약관 위반/스팸이 되는 요소는 넣지 않는다.
- JS 주입을 통한 자동 클릭/입력
- 동작 큐·자동 반복·딜레이·랜덤 타이밍(밴 회피)
- 친구 후보(낯선 사람) 대량 수집/타겟 리스트
- 확인창 자동 통과

즉 이 앱은 "5개 SNS를 편하게 모아 여는 전용 브라우저/런처"이며, 실제 조작은 사람이 한다.

## 구조
```
android/
  app/src/main/
    java/com/snshubcl/app/
      MainActivity.kt   # 대시보드(5개 SNS 카드, 언어 토글, 열기 버튼)
      WebActivity.kt    # 앱 내 브라우저(쿠키 유지, 뒤로/앞으로/새로고침, 파일 업로드)
      Sns.kt            # 플랫폼 정의(이름/색/진입 URL/패키지)
    res/layout/         # activity_main, item_sns, activity_web
    res/values(-en)/    # 문자열(한/영), 다크 테마
```

## 빌드 (CI)
로컬 툴체인 없이 GitHub Actions로 빌드한다.
1. `https://github.com/dicacros-gif/snshubcl` 레포 생성 후 푸시
2. **Actions → Build APK** 자동 실행(`android/**` 변경 시)
3. 결과물: Release `latest` 의 `app-debug.apk`

## 참고
- 로그인된 상태에서는 사이트 표시 언어가 **계정 설정**을 따른다. 한/영 토글은 주로 로그아웃 진입/첫 로드의 언어에 영향을 준다.
- 각 플랫폼의 이용약관과 커뮤니티 정책을 준수해 직접, 상식적인 범위에서 사용할 것.
